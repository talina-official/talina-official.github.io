# TALINA – link-in-bio

Сторінка з усіма посиланнями співачки TALINA: музика, блоги, навчання, SMM-агенція, жіночі заходи.

**Сайт:** https://talina-official.github.io/
**Репозиторій:** `talina-official/talina-official.github.io`, гілка `main`

Статичний сайт без збірки: один файл `index.html` (розмітка, стилі, дані посилань і скрипт рендеру) і папка `assets/`.

## Структура

| Файл | Що це |
| --- | --- |
| `index.html` | Уся сторінка. Посилання – у масиві `LINKS` у кінці файлу |
| `assets/avatar.webp`, `assets/avatar.jpg` | Аватар 800×800 (WebP + JPEG-фолбек). JPEG також іде в прев'ю для соцмереж (`og:image`) |
| `assets/avatar-original.jpg` | Оригінал фото, з якого зроблено аватар |
| `assets/favicon.svg` | Іконка вкладки: літера T кольору `--ivory` на колі `--red` |

## Як змінити посилання

Усі кнопки описані в масиві `LINKS` в `index.html`:

```js
{ group: 'ТВОРЧІСТЬ', theme: 'ivory', title: 'TikTok', sub: '@singer.talina.official', href: 'https://www.tiktok.com/@singer.talina.official', icon: 'tiktok' },
```

| Поле | Значення |
| --- | --- |
| `group` | Розділ, у який потрапляє кнопка: `ТВОРЧІСТЬ`, `МАРКЕТИНГ`, `ЖІНОЧІ ЗАХОДИ` або новий. Розділи йдуть у порядку першої появи в масиві, кнопки всередині – у порядку масиву |
| `theme` | Колір кнопки: `red`, `ivory`, `graphite`, `pink` (див. «Палітра») |
| `title` | Назва. Якщо в ній є ` \| `, на вузьких екранах (до 420px) друга частина переноситься на новий рядок, на ширших – показується через риску |
| `sub` | Дрібний підпис під назвою (необов'язковий): платформа і/або нікнейм |
| `href` | Адреса посилання |
| `icon` | Іконка: `instagram`, `tiktok`, `youtube`, `threads`, `music` |

Нова іконка додається як `<symbol id="i-назва">` у SVG-спрайт на початку `<body>`. Брендові іконки – з [Simple Icons](https://simpleicons.org/) (CC0), нота – Material Icons. Іконки зафарбовуються кольором тексту кнопки (`currentColor`).

**Нерозривні пробіли.** У назві «Творчий проєкт ART and WOMEN» між словами «ART and WOMEN» стоять нерозривні пробіли (U+00A0), щоб на телефоні «WOMEN» не переносилось окремо. У редакторі вони виглядають як звичайні – не замінюйте їх випадково.

## Палітра

CSS-змінні в `:root`:

| Змінна | Колір | Де використовується |
| --- | --- | --- |
| `--sky` | `#B3E5FC` | Фон сторінки, також `meta theme-color` |
| `--red` | `#8F2126` | Кнопки розділу «Творчість» (музика, блог), кільце аватара, favicon |
| `--ivory` | `#FAF2E1` | Текст на червоних кнопках; кнопки TikTok / YouTube / Threads у «Творчості» |
| `--graphite` | `#1C1C1C` | Текст сторінки, кнопки розділу «Маркетинг», текст на світлих кнопках |
| `--blue-text` | `#D7E2EE` | Текст на графітових кнопках |
| `--pink` | `#FFD7D9` | Кнопки розділу «Жіночі заходи» |

Теми кнопок: `red` – фон `--red`, текст `--ivory`; `graphite` – фон `--graphite`, текст `--blue-text`; `ivory` і `pink` – відповідний фон, текст `--graphite`.

Контраст тексту на всіх кнопках – від 7.8:1 (червона) до 15.3:1 (ivory), дрібних підписів – від 5.5:1; усе вище за WCAG AA (4.5:1).

## Дизайнерські рішення

- **Колір кнопки = розділ.** Тому при наведенні колір фону не змінюється – лише підйом на 2px і сильніша тінь (`@media (hover: hover)`). На тач-екранах натиск дає `scale(0.98)`, фокус з клавіатури – рамка 2px `--graphite`.
- **Світлі кнопки (ivory, pink)** мають рамку 1px `rgba(28,28,28,.12)` і тінь: рожевий за яскравістю майже збігається з блакитним фоном (контраст 1.03:1), тож від фону його відділяє саме рамка. Темні й червоні мають прозору рамку того ж розміру, щоб усі кнопки були однакової висоти.
- **Посилання відкриваються в тій самій вкладці** – навмисно: на телефоні так Instagram, TikTok і YouTube відкриваються у своїх застосунках.
- **Шрифт** – Manrope з Google Fonts (з кириличним набором).
- `prefers-reduced-motion` вимикає анімації кнопок.

## Відома особливість

На телефоні (375px) кнопки «Talina Eat | Інфлюенс маркетинг» і «Творчий проєкт ART and WOMEN» вищі за інші, бо назва займає два рядки. Узгоджено поки залишити так. Варіанти, якщо знадобиться: скоротити назви (напр. «Інфлюенс маркетинг» перенести в підпис) або вирівняти всі кнопки за найвищою.

## Що пробували і відмовились (жовтень 2026)

- **М'який фон `#D7E2EE`** замість блакитного – залишили блакитний `#B3E5FC`.
- **Текстура шкіри** поверх фону (сірий шар з `mix-blend-mode: multiply`, opacity 0.1) – не взяли. Робочі файли (`IMG_9512.PNG`, `assets/leather-gray.*`) у репозиторій не додані.

## Публікація

Сайт розгортає GitHub Pages з кореня гілки `main`:

```sh
git add <файли>
git commit -m "Опис змін"
git push
```

Зміни з'являються на сайті приблизно за хвилину. Нову favicon браузер може показати не одразу – допомагає Ctrl+Shift+R.

Налаштування репозиторію (Pages, доступи) змінюються з акаунта власника `talina-official`. Коміти робляться від імені `talina-official` з noreply-поштою, щоб особисті адреси не потрапляли в публічну історію.

## Перевірка перед публікацією

Відкрити `index.html` у браузері і переглянути на ширині 375px (телефон) та 1280px (десктоп): кнопки не обрізаються, підписи розділів читаються, світлі кнопки чітко видно на фоні.
